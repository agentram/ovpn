For operators and engineers

Self-hosted Xray operations controlled over SSH

ovpn is a Go CLI for operating Xray VLESS + REALITY hosts from local desired state. It renders Docker Compose runtime bundles, pushes them over SSH/SCP, and keeps maintenance practical across one server or a small fleet.

Advantages for operating many servers

The project focuses on repeatable operator workflows: local desired state, Docker-based runtime isolation, simple SSH automation, and enough diagnostics to maintain several VPN hosts without a separate control plane.

Desired state on servers

The CLI stores server and user state locally, renders Xray/Compose files, and deploys the same model repeatedly to remote hosts.

Easy automation

Commands are scriptable: add users, set quotas, deploy, run doctor checks, collect logs, back up, restore, and clean up old runtime.

Security baseline

Ansible handles host hardening. The minimal Xray profile blocks BitTorrent and public trackers; optional host rules block Tor exit traffic.

HA proxy topology

Proxy nodes can sit in front of backends, route local-country destinations directly, and relay foreign traffic with backend failover.

Highlighted architecture

The public endpoint is the VPN service itself. Operations happen from the operator machine over SSH/SCP, while the remote host keeps runtime pieces isolated in Docker Compose.

Automation and maintenance

The CLI is the operator surface. Release builds embed the Linux runtime assets, so normal deploys do not need Go, source checkout, or sidecar binaries next to ovpn.

  • server init and deploy render the desired state and apply it through SSH/SCP.
  • user add, user rm, quota-set, and expiry commands mirror users across enabled servers.
  • doctor, status, logs, backups, restore, cleanup, and monitoring are built-in workflows.
  • GitHub Actions validate Go, Ansible, security scans, and self-contained release packaging.
# Use a release archive, or build from source for development.
# Release archives contain one executable: ovpn.
# go build -o ovpn ./cmd/ovpn
./ovpn version

./ovpn server add \
  --name <server> \
  --host <server-ip> \
  --domain <domain> \
  --ssh-user root \
  --ssh-port 22

./ovpn server init <server>
./ovpn deploy <server>
./ovpn doctor <server>
./ovpn user quota-set --username <user> --monthly-gb 400
./ovpn user link --server <server> --username <user>
